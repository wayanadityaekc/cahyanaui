## 4. Final sweep: global Syntax and Naming rules still not followed

- Comments, arrow functions assigned to variables, string concatenation, catch variable, switch: none left (ESLint 0).
- async/await: `apps/cue/public/sw.js` still uses `.then()` chains and short names (`c`, `k`, `res`); `public/` is served as written and was left out on purpose.
- Loops: 11 `for` loops left (section 3).
- Functions: 59 names outside the verb list remain; 30 are published `packages/ui` exports or framework/exported names (section 3), the rest were judged already clear by the namer (`resendOtpCode`, `spreadDigits`, `adoptShellNodes`, `processBlock`, `fulfillJson`...).
- Negative names: `isNonNavigationLink` (4), `isNonPageLink` (2) remain; they read as positive tests (link type), kept.
- Magic numbers: 360 literals kept on purpose (content and test data values, formula offsets).
- Lists: 95 inventory hits are not arrays (strings from `slice`, servers, single nodes); none left that is a real array with a singular name.
- Destructuring props, spread copies, early returns in long functions: not measurable by a tool; checked only where code was touched.
